It works—until it has to travel.

The message lands in conversation. It holds when explained. It carries when attention is shared.

Then it moves.

It is sent, posted, forwarded, revisited.

The same words. The same structure. The same intent.

Something doesn’t survive.

What felt clear becomes partial. What felt central becomes easy to miss. What held attention now competes for it.

Nothing changed in the message.

Only where it lives.

What must this message survive?

Begin by testing its durability.

  • What will still hold if this is skimmed?
  • What will be seen if only part of it is read?
  • What disappears when attention drops?

Now decide:

  • Does this message need a different channel?
  • Or does it need to change so it can survive this one?

The message is not what you send.

It is what continues to hold after it moves.
